0086 03 Kiến trúc và API hiện có
0087 API là cách giao diện trao đổi dữ liệu với chương trình xử lý. API nội bộ của app hiện miễn phí; chỉ khi tích hợp dịch vụ bên ngoài mới có điều kiện giá, quota và quyền truy cập riêng.
0088 Trình duyệt → HTTP JSON → Service → Rules và Engine → lời giải theo mẫu → SQLite → màn hình. Engine và lời giải tách riêng để thay thế sau này.
