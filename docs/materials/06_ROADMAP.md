# ROADMAP

## Week 1
Proof of learning loop.

## Weeks 2–4
Usable alpha:
- 100+ verified positions
- auth/db hardening
- better taxonomy
- feedback pipeline
- analytics
- online PvP if core stable
- mobile responsive
- 10–30 real testers

## Month 2
Adaptive learning:
- learner profile v2
- scheduler refinement
- lesson library
- puzzle candidate mining
- gold set expansion
- ML baseline notebook

## Month 3
ML experiment only if data supports:
- mistake classifier
- retention prediction
- puzzle ranking
- compare against heuristic baseline

## Months 4–6
- better PvP
- openings/endgames
- bilingual
- PWA
- community/pilot

## Gate
Không đi tiếp nếu:
- rules unreliable;
- explanations hallucinate badly;
- source/license unclear;
- no user evidence;
- owner không hiểu architecture.
